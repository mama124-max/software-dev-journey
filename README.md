# Software Dev Journey

This is my learning folder. I use it to practice real software development, not guessing.

Each lesson is a small, finished step. GitHub keeps a history of every change.

## How I work (so I do not "vibe code")

1. Write the goal in plain English.
2. Ask questions until the goal is clear.
3. Build the smallest version that works.
4. Read the code and explain it in my own words.
5. Save the work to GitHub.

## If someone asks me to build a website

I ask these eight things first:

1. Purpose — what is the site for?
2. Audience — who will use it?
3. Pages — which pages are needed?
4. Content — who provides text, photos, and logo?
5. Look — any example sites or colors?
6. Actions — what should a visitor do (call, form, pay, book)?
7. Constraints — deadline, budget, phone and desktop, language
8. After launch — who updates it, hosting, domain name
