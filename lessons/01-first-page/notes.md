# Lesson 01 — First web page

## Goal

Make one web page I can open in a browser, then save it to GitHub.

## What each file is for

- `index.html` is the content: headings, paragraphs, structure.
- `styles.css` is the look: colors, spacing, fonts.
- This `notes.md` file is my explanation in my own words.

## Words I should know

- **HTML** = the skeleton of a page (what is on it).
- **CSS** = the clothes of a page (how it looks).
- **Git** = a notebook of changes on my computer.
- **GitHub** = that notebook stored online so I can see my history.

## How to open this page

1. Open `index.html` in a browser (double-click the file, or right-click and choose a browser).
2. Read the page.
3. Later, change the heading to my real name.

## What I will not do yet

I will not add JavaScript, a login system, or a full business website. One working page is enough for this lesson.
